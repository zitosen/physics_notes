# Physics Notes

**Living Physics Notes｜持续更新的物理学讲义与知识平台**

本项目旨在建立一个长期维护、持续更新、版本可追踪的物理学知识平台。

它不同于一次性完成的传统教材，而是一套随着教学、科研和学习过程不断演化的 **Living Lecture Notes（活的讲义）**。

## 当前内容

### 群论及其在物理学中的应用

面向物理学及相关专业本科高年级学生和研究生的群论讲义。

讲义从物理学中的对称性问题出发，逐步建立群、群表示、不可约表示、特征标以及点群等数学结构，并讨论其在量子力学、晶体学和其他物理问题中的应用。

在线阅读：

https://zitosen.github.io/physics_notes/

## 内容组织理念

本项目强调数学结构与物理直觉之间的联系，基本思路是：

**物理问题 → 对称性 → 数学结构 → 物理解释 → 具体例子 → 物理应用**

这里的目标不是降低数学严谨性，而是降低进入抽象数学概念的门槛。

## Living Lecture Notes

本项目采用持续更新的方式维护。

在线版本反映当前内容状态。随着教学和研究的推进，讲义中的内容、结构、公式、例题和表述可能持续修改。

对于具有较大意义的阶段性版本，将通过 Git 标签（tag）、GitHub Release 或固定版本文件进行保存，以便引用和长期追踪。

## 技术框架

本项目使用以下工具维护和发布：

* Git：版本控制
* GitHub：源代码与版本管理
* Quarto：讲义生成
* GitHub Actions：自动构建与发布
* GitHub Pages：在线发布

基本流程：

**编辑讲义 → Git 提交 → GitHub → 自动构建 → 在线发布**
